# Tarjeta profesional — Sandro Romero

Sitio web personal de **Sandro Fabrizzio Romero Bejarano**, creado para presentar su perfil, formación, proyectos y medios de contacto.

## Publicación en GitHub Pages

1. Abre **Settings → Pages** del repositorio.
2. En **Build and deployment**, selecciona **Deploy from a branch**.
3. Selecciona **main** y la carpeta **/(root)**; guarda.
4. Espera a que GitHub indique la dirección pública: **https://lzenaku.github.io/tarjeta-profesional/**.
5. Abre la dirección desde el celular y comprueba el QR mostrado en la sección Contacto.

## Archivos

- `index.html`: contenido de la tarjeta.
- `styles.css`: diseño adaptable y temas claro/oscuro.
- `script.js`: interacción, animaciones accesibles y opción de compartir.
- `qr.svg`: QR con la URL pública de GitHub Pages.
- `favicon.svg`: ícono del sitio.
